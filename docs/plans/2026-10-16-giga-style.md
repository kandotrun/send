# send: ギガサイト便スタイルへの刷新

ユーザー指定: UIを [ギガサイト便](https://giga-site.com/)（`kandotrun/ai-slop`）寄りにする。アクセント色は [txt](https://txt.2-38.com/) の青。ダークモードはOS設定追従のまま維持する。

## 方向性
- ギガサイト便の「Shadcnの構造 × Bootstrap 2のやわらかい光沢」を移植する。上明→下暗の微グラデ、上端ハイライト、低く柔らかい影。
- 塗りは `background-color`、光沢は `background-image`（`--gloss`）に分ける。光沢面に `background:` ショートハンドを使わない。
- 青は3段で使い分ける。`--brand #0a84ff` は文字以外の印（ワードマークの点・選択タブの枠・フォーカス）だけ。文字は `--accent`、主ボタンは `--accent-fill`。
- `#0a84ff` は白地でも白文字でも 3.65:1 で本文AAに届かないため、主ボタンは色相を保った `#004dc4` とする。光沢の最も明るい点（白22%合成）でも白文字 4.5:1 以上。
- ダークは txt の暗色に寄せ、主ボタンは `#4c9aff` に暗色文字（光沢の最も暗い点でも 4.5:1 以上）。

## 画面構成
| 部位 | ギガサイト便の元 | send での形 |
| --- | --- | --- |
| 最上部 | 黒帯のお知らせ | 初期ベータ版・登録不要・容量上限 |
| ヘッダー | 半透明・blur・下線、右にボタン | 光沢タイル＋`send.`、右にソースコードへのアウトラインボタン |
| ヒーロー | 中央揃え、流れるグラデ見出し、青い放射状の淡い地 | 送信画面だけ表示。h1 の `textContent` 書き換えを壊さないよう h1 自体を `background-clip: text`。流れは1回・4.8秒で止める（WCAG 2.2.2） |
| ドロップ | 2px点線・18px角丸・60px光沢アイコンタイル | 同形。ドラッグ中は `--brand` の実線枠と青い光輪（強制カラーでも線種で分かる） |
| ボタン | 光沢の塗りボタン・アウトライン | 主ボタン・コピーは光沢、副次はアウトライン、取り消しは赤のアウトライン |
| タブ | セグメント（白→淡青、ベベル） | 選択中は `--brand` の枠で色以外にも区別 |
| 補助 | well（へこみ）、アラート（重要度別グラデ） | 送る前に・管理リンク控え・受信文章は well、注意は警告アラート |
| フッター | 罫線つきの淡い帯 | 安全性の折りたたみカード＋淡い帯 |

## 制約（変更しない）
- 暗号・API・送受信の振る舞い、`main.ts` が参照する id・`data-*`・`.is-dragging`。
- CSP（`style-src 'self'`・`img-src 'self'`）。`style=` 属性、`<style>`、CSSの `url()`（data URI含む）、外部フォント・外部スクリプトを使わない。
- 必須トークンは6桁hexで `:root` と `@media (prefers-color-scheme: dark) { :root {` に定義する。本文 4.5:1、選択タブ枠 3:1、文字 12px 以上。
- `prefers-reduced-motion` ではグラデの流れ・浮き上がりを止める。
- 固定ヘッダーの下にフォーカス先が隠れないよう `scroll-padding-top` を取る（WCAG 2.4.11）。角丸で `overflow: hidden` のカード内は、フォーカス輪郭を内側に描く。
- 強制カラー（Windows ハイコントラスト）では選択タブと進行バーをシステム色で描く。
